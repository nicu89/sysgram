sysgram gallery

One diagram per capability. Every figure below is generated from the JSON spec right above it in this file's source — view source (or Read the file) to see exactly how each effect is authored. Hover nodes or edges to trace them; click anything to pin an inspector with its facts and connections; drag to pan; ⌘/ctrl-scroll or the toolbar to zoom.

1 · Node kinds

Every archetype in the catalog. Shape + glyph carry the meaning, so kinds survive grayscale and colorblindness. rank/order hints arrange the grid — the only time hints are routinely needed is edge-less diagrams like this one.

2 · Catalog icons (SVG)

Real product artwork via iconCatalog + per-node icon (one or two per node). Icons are optional presentation metadata — meaning always comes from kind, and a missing file falls back to the semantic glyph. Provenance for these AWS icons: assets/aws/README.md.

3 · Edge kinds

The full connection taxonomy — dash pattern + arrowhead + weight carry the meaning, color only reinforces. Note the domain-specific kinds: webhook is a hint (amber, never truth), isolation is a deliberate non-connection with a ⫽ mark. both:true puts heads on both ends; tone recolors one edge.

4 · Zones, nesting, mixed directions

Groups contain nodes or other groups. Each group may set its own direction — mixing axes is the main tool for compact layouts. Styles: dashed (permeable), solid (hard boundary), tint (filled region).

5 · Bands (cross-cutting concerns)

"band": true pulls a node out of the flow and stretches it across its container's full width at the bottom — for observability, compliance, and other everything-touches-it strips.

6 · Steps and flows

step numbers a single edge; flows name ordered edge sequences and become clickable chips that spotlight their path. Click a chip, then click it again to release.

7 · Tones, tints, badges, links

tone recolors border + title (accent / warn / muted); tint fills the body; badges are tiny mono pills; href makes the node a link (this one opens the SPEC).

8 · Routing

Default routing is a curve; ortho gives right-angle runs with rounded corners, straight a direct line. Set per edge. With route:"smart" (the default) an auto edge whose curve would cross an unrelated node reroutes itself orthogonally around it — the skip edge below detours instead of lancing the middle node.

9 · Facts, assertions, and the inspector

facts attach structured semantics (protocol, trust, consistency…) to nodes and edges — hover for the tooltip, click for the inspector panel. assertions record rules no arrow can draw; ones with refs spotlight their subjects when clicked. An assertion may add an executable rule (forbid-edge / forbid-path / only-via / require-edge) — the validator proves it against the edge graph and the row wears a "✓ machine-checked" chip; if the diagram ever contradicts it, validation errors. The provider sits in a trust-boundary group (amber by default): crossing that border is what the webhook rules are about.

10 · Manual arrangement

"arrange": "manual" switches to authored at: [x, y] coordinates for carefully composed reference views. Sizes are still computed (labels never clip), groups still fit their members, and edges still route smartly — it stays a semantic graph, not a drawing. Prefer auto + hints everywhere else.

11 · Layout families

The same little system rendered under each layout family. The family is declared in the spec — never a viewer control — so every reader and every agent sees the same picture. layered (default) fits flows; tree fits hierarchies (a node's parent is its first cycle-free in-edge, extra edges become cross-links); radial rings the highest-degree hub; sequence fits conversations — participants become lifelines, one row per message ordered by step, so many labeled calls between the same pair can never collide (that shape smears any topology layout). Tree, radial, and sequence are flat: groups/bands are a validation error there.

12 · Forced theme

Diagrams follow the page's light/dark preference by default; data-sysgram-theme="dark" (or "light") on the spec's script tag pins one. Dark is its own tuned palette, not an inversion.

13 · Validation feedback

Broken specs never fail silently: errors render as a panel (and land in window.sysgram.get(id).errors + the console). This one references a node that doesn't exist and reuses an id.

A violated assertion rule is also an error — the spec states an invariant its own edges contradict. Here the text says the cache is never written directly, but an edge does exactly that.
